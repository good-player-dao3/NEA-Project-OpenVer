# 本地作品

`works/` 是用于开发和验证 NEA 兼容性的本地地图目录。

实际导出的项目、脚本、截图、捕获元数据以及其他私有作品材料应存放在：

///text
works/private/<work-id>/
///

`works/private/` 已被 Git 忽略。切勿将私有作品源移至受跟踪的测试夹具中。仅将最低必要的行为转换为经过脱敏的 ABI 证据、合成的兼容性测试夹具和兼容性报告。

每个私有作品目录应包含一个 `work-manifest.json`，记录：

- 本地稳定标识符；
- 所有者提供的显示标签；
- 原始捕获目录；
- 导出完整性和已知缺失数据；
- 生成的分析路径。

原始的 `dump/private/live-captures/` 目录应作为不可变的捕获来源。作品目录包含开发副本，不得替换或删除该源证据。

兼容性工具将这些目录作为匿名脚本语料样本导入。作品名称和标识符不得出现在运行时分支、ABI 标识符、兼容性行为或生成的兼容性报告中。
