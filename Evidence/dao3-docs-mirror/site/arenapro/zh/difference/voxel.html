改进说明 ​

修改背景 ​

在原先的官方 d.ts 文件中，该 API 接口的方块数据被宽泛地定义为number或string类型，这可能会引发以下问题：

  • 允许输入任意数据
  • 运行时可能因无法获取对应方块而产生 BUG

改进方案 ​

因为神岛方块是有限的，我们引入了自定义类型来严格规范输入数据。

改进效果 ​

  • 确保数据合法性
  • 提升代码可读性
  • 增强错误检查能力
