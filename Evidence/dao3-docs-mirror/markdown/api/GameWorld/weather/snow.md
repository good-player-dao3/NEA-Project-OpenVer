# 天气-雪

### 属性

#### snowColor:[GameRGBAColor](/api/GameRGBAColor/index.md)

> 默认值：GameRGBAColor(1, 1, 1, 1)

雪花颜色。

---

#### snowTexture: string

> 默认值：无

雪花纹理。此处填写文件管理器中的纹理资源名称。如 'snow/heart.part'

---

#### snowDensity: string

> 默认值：0

雪的密度。密度越大，雪花越多。

---

#### snowFallSpeed: string

> 默认值：1

雪花下落速度。如果小于0，则反向运动。

---

#### snowSpinSpeed:[GameVector3](/api/GameVector3/index.md)

> 默认值：GameVector3(0, 0, 0)

雪花自旋速度。

---

#### snowSizeLo: number

> 默认值：0

雪花的最小直径。

---

#### snowSizeHi: number

> 默认值：1

雪花的最大直径。
