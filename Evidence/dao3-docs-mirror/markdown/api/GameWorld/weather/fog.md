# 天气-雾

## 属性

#### maxFog: number

> 默认值：1

最大雾量。

---

#### fogColor:[GameRGBColor](/api/GameRGBColor/index.md)

> 默认值：GameRGBColor(1, 1, 1)

雾的颜色。

---

#### fogStartDistance: number

> 默认值：0

雾起始距离。

---

#### fogHeightOffset: number

> 默认值：0

雾高度。

---

#### fogUniformDensity: number

> 默认值：0

均匀雾量，若值大于0，越难看到天空。

---

#### fogHeightFalloff: number

> 默认值：0.8

高度衰减系数。数值在0-1之间。值越小，雾越浓。
