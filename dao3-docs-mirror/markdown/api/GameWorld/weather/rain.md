# 天气-雨

### 属性

#### rainSpeed: numberrainColor

> 默认值：1

雨的速度。

---

#### rainColor :[GameRGBAColor](/api/GameRGBAColor/index.md)

> 默认值：GameRGBAColor(1, 1, 1, 1)

雨的颜色。

---

#### rainDirection :[GameVector3](/api/GameVector3/index.md)

> 默认值：GameVector3(0, 1, 0)

雨的方向。

---

#### rainDensity: number

> 默认值：0

雨的密度。

---

#### rainInterference: number

> 默认值：0

雨的不规则性。

---

#### rainSizeLo: number

> 默认值：0

雨滴的最小直径。

---

#### rainSizeHi: number

> 默认值：1

雨滴的最大直径。
