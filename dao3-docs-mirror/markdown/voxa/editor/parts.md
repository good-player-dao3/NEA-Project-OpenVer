# 部件界面布局

![](/voxa/QQ20241113-001236.png)

### [视口窗](./parts/shortcutKeys.md)

提供文件的可视化窗口

### [全局工具栏](./parts/globalToolbar.md)

切换模型/动画编辑以及针对文件的命名和保存等操作

### [编辑工具栏](./parts/editToolbar.md)

基础的文件操作（包括位移，旋转，复制）和创建骨骼

### [辅助工具栏](./parts/auxiliaryToolbar.md)

命令撤销/撤回以及对视口窗可视化内容的调整

### [属性面板](./parts/propertiesPanel.md)

提供对部件的基础属性操作

### [部件/骨骼列表](./parts/bone.md)

资源列表（包括部件和骨骼）
