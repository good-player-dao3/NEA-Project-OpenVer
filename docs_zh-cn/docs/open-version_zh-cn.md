# 开放版本政策

`NEA Project OpenVer` 是 NEA 保护和兼容工作的可发布仓库。它的职责是提供实现、可复现报告和经过审查的证据，同时不暴露属于本地操作员、账户或私有捕获作品的材料。

## 包含内容

- 可执行的兼容性代码和确定性的生成 ABI/报告工件。
- 公共文档镜像、历史声明、传输源和捆绑包，这些均已审查可在本仓库发布。
- 经过清理的作品元数据和可复现的导入/运行时工具。

## 排除内容

- 浏览器配置文件、Cookie 存储、登录数据库、OAuth 材料、凭证、会话状态和含有令牌的 URL。
- `dump/private/`、`works/private/`、`Lokibox/`、`.workspace/` 以及用户拥有的 `NEA-Project.7z` 归档。
- 私有地图导出、脚本源代码、捕获数据或任何发布状态不明的内容。

## 发布检查清单

在提交或推送开放版本之前：

1. 检查 `git status --short`，确认忽略/私有位置不存在。
2. 检查暂存路径中是否包含上述排除列表中的项目。
3. 保持生成的 ABI/报告文件与生成它们的实现同步。
4. 使用基于证据的兼容性描述语言：`compatible`（兼容）、`partial`（部分）、`recovered-only`（仅恢复）、`declared-only`（仅声明）或明确的证据待定注释。
5. 不要仅仅为了隐藏不确定的文件而重写历史。先停止并审计它。
