# NEA Project 中文文档

本目录存放项目的中文说明、中文进度摘要和面向中文使用者的操作指引。

## 文档边界

- `Docs/`：英文工程文档、架构、进度、仓库治理和 AI 上下文。
- `Docs/zh/`：中文解释、中文入门和中文项目管理说明。
- 外部外挂/绕过项目的名称、路径和导入不得出现在脚本或实现代码中；相关行为必须重建为项目内的中性证据 fixture。
- 源代码、测试名称、运行时诊断和 AI 开发任务默认使用英文。

## 当前入口

- 英文实时进度：`../Docs/project-progress.md`
- 英文仓库整理计划：`../Docs/repository-cleanup-plan.md`
- 英文 AI 上下文：`../Docs/ai/project-context.md`

## 中文项目管理

当前项目主线是：

1. 生成真实地图的 ABI 兼容性缺口报告。
2. 选择一个最高优先级的客户端 remoteChannel/UI 行为。
3. 用 conformance test 和 `demo-map` 可见行为证明它完成。

中文文档可以解释背景和操作方式，但不要替代英文工程文档中的契约、验收标准和实现记录。
